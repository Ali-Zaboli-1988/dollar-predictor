# Real training data

`tgju_usd_free_market.csv` is a small real-data seed dataset of Iranian free-market USD/IRR closing prices.

Source: TGJU USD free-market historical archive (`price_dollar_rl`). TGJU's archive publishes daily open, low, high, close, change, percentage change, Gregorian date, and Solar date.

The committed rows cover 2026-07-28 through 2026-09-05 for the observations visible in the TGJU archive snapshot used for this seed dataset.

Units: Iranian rial per USD.

This file is deliberately kept separate from the generated enriched dataset. News features are generated by `tools/build_news_features.py` at CI time from historical GDELT article data. The generated file is uploaded as a workflow artifact and is not treated as source-controlled ground truth.

Important temporal rule: a row dated `t` may only contain information available by the defined decision cutoff on `t`; the next observed close is the target for one-step directional evaluation.
